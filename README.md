# Hearth & Grain Bakery 🥖✨

A modern, fully responsive, and artisan-themed React frontend built for a boutique bakery. The project highlights slow-fermented sourdough, daily schedules, interactive menu showcases, and elegant brand storytelling.


## 🌟 Key Features

- **Responsive Mobile-First Architecture:** Custom CSS media queries ensuring seamless layouts across mobile, tablet, and desktop viewports.
- **Sticky Glassmorphism Header:** Sleek navigation bar with smooth scrolling triggers and a fully responsive mobile drawer toggle.
- **Modular Component Structure:** Clean, component-driven architecture separating headers, menus, schedules, stories, and footers.
- **Interactive Daily Schedule Grid:** Dynamic day-by-day highlight section displaying specific daily bakes and operation hours.
- **Artisan Menu Showcase:** Clean, well-spaced category cards featuring item pricing, descriptions, and custom dotted leader layouts.


## 🛠️ Tech Stack

- **Frontend Library:** [React](https://react.dev/) (Functional Components)
- **Styling:** Vanilla CSS3 (Custom Properties, Flexbox, CSS Grid, and Fluid Typography)
- **Typography:** Google Fonts ([Fraunces](https://fonts.google.com/specimen/Fraunces) & [Work Sans](https://fonts.google.com/specimen/Work+Sans))
- **Build Tool:** Vite


## 🚀 Getting Started

To get a local copy up and running, follow these simple steps:

### 1. Clone the Repository
```bash
git clone [https://github.com/vamtech-in/Hearth-Grain-Bakery-.git](https://github.com/vamtech-in/Hearth-Grain-Bakery-.git)
cd Hearth-Grain-Bakery-

2. Install Dependencies
Bash
npm install

3. Run the Development Server
Bash
npm run dev
Open http://localhost:5173 to view it in your browser.
